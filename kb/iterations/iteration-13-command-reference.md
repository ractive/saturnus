# Iteration 13: Command reference with emulator-generated examples

Read first: `kb/docs/clean-room-rule.md`, `crates/saturnus-mcp/src/semantic.rs`
(`eval` and the typed `Object`), wiki `protocols/server-commands`,
`protocols/hp-object-format`.

## Context (2026-10-05)

- Owner: "an easily findable list of all commands with a help and
  examples", with the caveat that HP's manual text may not be usable.
- Copyright position: the command names, their categories and what they
  take and return are facts; HP's descriptions and the exact arrangement
  of the Advanced User's Reference are HP's expression and are not copied
  or closely paraphrased. Descriptions are written from scratch (one or two
  sentences, ours). Examples are generated by running each command on the
  emulator with chosen inputs and recording the typed results, so they are
  verified by construction and show the ROM's own output format.
- Manuals as fact inputs (owner, 2026-10-05): the user's guides and the
  Advanced User's Reference are used to check facts (arguments, modes,
  flags affecting a command, error names) and the ROM's command catalog
  gives the list; the text is still written by us. Availability checked
  online 2026-10-05: HP's manuals are freely downloadable (hp.com,
  literature.hpcalc.org hosts them "with permission") but carry the
  notice "Reproduction, adaptation, or translation of this manual is
  prohibited without prior written permission of Hewlett-Packard Company";
  no Creative Commons or public-domain release was found. Option: ask the
  current HP calculator licensee (Moravia Consulting runs the HP calculator
  business for HP Inc. since 2022) for written permission to reuse the AUR
  command descriptions; until then, own text only.
- The command list comes from the ROM itself (the command catalog per
  model), extracted through the emulator, so model coverage is exact.

## Tasks

- [ ] Extract the command name list per model from the ROM (the catalog),
  with the category the ROM's menus put it in; store as data in the repo.
- [ ] A generator (Rust, using the MCP `eval` machinery in-process) that
  runs curated inputs per command on each model and writes the examples
  (inputs, outputs, error text) as JSON; re-runnable; commands that need
  interaction (prompts, plots) marked as such with a screen capture
  instead.
- [ ] Our own descriptions, one or two sentences per command, written
  from the command's observed behaviour and the stack diagram derived from
  the runs; reviewed for not resembling the manual's wording.
- [ ] A reference panel in the web UI: search by name, category,
  description and example text; per-model availability; a "try it"
  button that pushes an example onto the running calculator (through
  `eval`); keyboard access (a shortcut opens the search).
- [ ] The same data served as an MCP resource so agents can look commands
  up.

## Acceptance criteria

- [ ] Every command of the 48SX catalog has an entry with a description
  and at least one generated example; search finds `STO` by typing "sto"
  or "store"; "try it" on an example reproduces its output on the
  calculator.
