title: Command reference

section: commands
---

Choose a model, then search for a command by its name or by words of what it does. A name can be typed in plain letters: `->LIST` finds `→LIST`, `SIGMA+` finds `Σ+`. Each command has its own address, for a link: [HMS- on the 48GX](commands.md#48gx/hms-).

The examples were run on the emulated calculator and show what its display showed: the stack before, the command, the stack after. On the 42S, 27S, 17BII, 17B, 19BII, 38G, 39G and 40G a function is pressed, not typed: their examples show the display before, the keys and the display after. In the app, Search finds the same commands and runs them on the calculator.

Each model's commands are also one Markdown file: [48SX](commands/48sx.md), [48GX](commands/48gx.md), [49G](commands/49g.md), [38G](commands/38g.md), [39G](commands/39g.md), [40G](commands/40g.md), [42S](commands/42s.md), [27S](commands/27s.md), [17BII](commands/17bii.md), [17B](commands/17b.md), [28S](commands/28s.md), [19BII](commands/19bii.md).
