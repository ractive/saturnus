Every command of the 12 calculators, with its stack effect, what it does and examples with their results from the emulated calculator. Search by name or by what a command does; `->LIST` finds `→LIST`, `SIGMA+` finds `Σ+`. Or browse a model's commands by menu.

## Reading an example

An example shows the stack before, the command, and the stack after, as the emulated calculator displayed them. On the 42S, 27S, 17BII, 17B, 19BII, 38G, 39G and 40G a function is pressed, not typed: their examples show the display before, the keys, and the display after.

Each command has its own address, for a link: [HMS- on the 48GX](commands.md#48gx/hms-). The model pills in an entry lead to the same command on the other models. In the app, Search finds the same commands and runs them on the calculator.
