            Trouble with the cable?
            • The calculator needs its own serial cable, and most computers a USB serial adapter for it.
            • On Linux, your user must be in the dialout group (uucp on Arch) to reach the port.
            • On Windows, adapters with fake Prolific chips are refused by current drivers; one with an FTDI or a genuine chip works.
            • Files finds the speed and parity by itself. If that fails, set them here; the calculator starts at 9600 baud with no parity.

            On the palmtop, put Filer in server mode:

            1. Open Filer.
            2. Press MENU, then choose Communications, Remote Settings.
            3. Set Baud to 19200, Interface to COM1 and Server Mode on. Press OK.
            4. Leave Filer open and in front while Files works with it.

            Use the palmtop's own cable. Never plug the palmtop's cable into an HP 48 or 49G, and never use a 38G cable or adapter on the palmtop: the plugs fit, but the wiring differs and can damage the device.

            Trouble with the cable?
            • HP's palmtop cable ends in a serial plug with the null modem built in: plug a USB serial adapter straight into it, nothing in between.
            • At the palmtop, the plug goes in with the HP logo up.
            • On Linux, your user must be in the dialout group (uucp on Arch) to reach the port.
            • Files talks at 19200 baud. If you set the palmtop faster, set the same speed here.

            Above 19200 the palmtop's serial chip may lose bytes, so a copy can fail part way. If it does, go back to 19200.
