saturnus

A clean-room emulator of the Saturn calculators, running in your browser.

The ROM is read in this page only; it is never uploaded or stored. Saved states stay in this browser (IndexedDB), one per model.

Pick a model and a ROM file to start.

Keyboard

Digits, + - * /, ., Space, Enter, Backspace, Delete (DEL), arrows, ' (quote), ^ (power), Esc = ON, F1-F6 = the menu keys. Click or tap the drawn keys for the rest.
