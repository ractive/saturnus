The HP 48, in your browser.

saturnus emulates the HP 48SX, HP 48GX, HP 49G, HP 38G, HP 39G, HP 40G and HP 42S. Use it in the browser, as a desktop app or from the command line.

Open the emulator Desktop and command line

Free and open source (MIT). Nothing is uploaded: the ROM and your work stay on your device. No ROM is included; get one from hpcalc.org.

What you can do

  • Type and paste RPL

    Paste a program and the page types it into the command line, key by key. Your keyboard's letters, digits and Enter go to the calculator; F1 to F6 are the menu keys.

  • Look inside the memory

    The memory view shows the variables, directories, stack and flags, read live from the calculator's RAM. Store, rename, purge, set a flag: the calculator does it itself.

  • Edit programs

    Open a variable or a stack level in an RPL editor with highlighting, indentation and completion. The calculator compiles what you save, so a syntax error is its own message.

  • Look up any command

    Cmd+K or Ctrl+K opens the command reference: every built-in command of the 48SX, 48GX and 49G, with stack effects and examples that were run on the emulator. Enter sends it to the calculator.

  • Keep your work

    The calculator keeps its memory across reloads, as a real one does when switched off. Save and load states, and copy or save the screen as a PNG.

  • Real speed, or faster

    Programs take as long as on the real calculator, within a few percent. Switch to 2x, 4x or Max when you are waiting on a long one.

The memory view, the editor, pasting and the command reference work on the 48SX, 48GX and 49G.

Get it

Web

Nothing to install. The page works offline after the first visit and can be added to a phone's home screen.

Open the emulator

Desktop app

macOS (Apple silicon), Windows and Linux. The app downloads a model's ROM from hpcalc.org for you, after asking.

Download from the releases page

The Mac app is signed and notarised. Windows will ask once before the first start; the release notes say what to click.

Command line

Run a ROM with a key script, save the screen, serve the serial port for Kermit, or drive the calculator from a script.

brew trust --formula ractive/tap/saturnus   # once
brew install ractive/tap/saturnus
cargo install saturnus-cli
scoop bucket add ractive https://github.com/ractive/scoop-bucket
scoop install saturnus

Also as .deb and .rpm on the releases page, and as crates on crates.io.

The ROM is not included

saturnus runs the calculator's own ROM, which is HP's software. hpcalc.org hosts the ROM files with HP's permission for use with emulators, and saturnus does not host or pass them on. Download the ROM for your model there, unzip it and drop the file on the page; the desktop app and saturnus rom fetch download it for you. The 42S ROM was never published: it must be read out of your own calculator.

Written from the documentation

saturnus was written from HP's manuals, the hardware literature and the behaviour of the ROMs themselves, not from other emulators' source code. Every fact it relies on is in a public knowledge base with its source: the Saturn CPU, the display, the timers, the serial port, the memory layout and the transfer protocols.
